# agy-stack: agy + webide в одном контейнере

Заменяет `ttyd`. Внутри контейнера работает веб-IDE: слева дерево, поиск и Git, справа редактор, снизу терминал с agy.

```
agy-stack/
├─ docker-compose.yml   сервис agy-cli (ваша сеть xray_client_default, прокси socks5h)
├─ Dockerfile           ubuntu:24.04 + entrypoint + webide
├─ entrypoint.sh        при старте: пакеты, agy, Monaco/xterm, git-настройки, запуск webide
├─ .env.example         пароль, git-имя, адрес привязки
├─ projects.json        пресеты проектов
├─ webide/              server.py + index.html + lang/ (ru.json, en.json) + tgbot.py + agy-run
├─ projects/            ваши проекты (каждая подпапка = проект)
├─ agy-auth/            авторизация agy, токены git, флаги проектов, привязки Telegram (создаётся само)
└─ state/               бинарник agy, Monaco/xterm, ssh-ключи, gemini/settings.json (создаётся само)
```

## Запуск

```sh
cp .env.example .env          # впишите AUTH_PASS (обязателен), GIT_USER_NAME/EMAIL
mkdir -p projects
mv ../my-project projects/    # ваш старый ./my-project теперь один из проектов
docker compose up -d --build
docker compose logs -f        # первый старт: apt, agy и Monaco качаются через прокси
```

Открыть `http://localhost:7681`, логин `agy`, пароль из `.env`. Порт по умолчанию слушает только localhost; для доступа по сети поставьте `WEBIDE_BIND=0.0.0.0` и обязательно HTTPS-прокси перед ним: доступ к UI равен шеллу в контейнере.

Что где сохраняется:
- `docker compose restart`: ничего не переустанавливается.
- `docker compose up -d --force-recreate`: apt-пакеты поставятся заново (около минуты), agy, Monaco и авторизация лежат в томах и остаются.
- правки в `webide/` или `projects.json`: достаточно `docker compose restart`, пересборка не нужна.

## Git (как в VS Code, в рамках нужного для работы)

Вкладка **Git** (Ctrl+Shift+G), бейдж показывает число изменений, в дереве файлы подсвечены цветом и буквой (M, U, A, D, C).

- **Подключиться к существующему репозиторию:** кнопка `＋` у списка проектов → вставить URL → репозиторий клонируется в `projects/<имя>` и открывается.
- **Свой пустой проект + remote:** `＋` без URL, затем «Инициализировать репозиторий» и «Добавить адрес remote…».
- **Синхронизация:** кнопка «⇅ Синхронизировать ↓N ↑M» делает pull и push (для новой ветки публикует её с upstream). Отдельно: Pull, Push, Fetch.
- **Индекс и коммит:** `+` и `−` у файла или у секции, `↩` отменяет изменения (с подтверждением), сообщение и Ctrl+Enter. Если ничего не добавлено в индекс, предложит закоммитить всё.
- **Ветки:** выпадающий список (локальные и удалённые), `⑂＋` создаёт новую от текущей.
- **Diff:** клик по файлу в списке изменений открывает сравнение с HEAD, правки в правой части можно сразу сохранять. Кнопка `Δ Diff` над редактором включает то же для открытого файла.
- **История:** последние 30 коммитов.

### Доступ к приватным репозиториям

- **HTTPS:** кнопка 🔑 → хост (`github.com`), логин, токен. Сохраняется в `agy-auth/git-credentials`, работает и для UI, и для `git` в терминале.
- **SSH:** положите ключ в `state/ssh/id_ed25519` (права выставятся сами). Git ходит по SSH через ваш socks-прокси (в compose уже прописан `GIT_SSH_COMMAND` с `nc -X 5`). Если порт 22 закрыт, используйте `ssh://git@ssh.github.com:443/user/repo.git`.

Команды git без интерактивного ввода: пароль у UI не спрашивается, поэтому для приватного репозитория сначала сохраните токен.

## Файлы

Правый клик по дереву или кнопки над ним: новый файл (можно `dir/sub/name.ext`, папки создадутся), новая папка, переименование и перемещение (F2, можно указать другой путь), удаление (Delete, с подтверждением). Открытые вкладки подстраиваются сами.

**Файлы, которые меняет агент, обновляются в редакторе сами** (обычно за 1–2 секунды; пока в терминале идёт вывод, проверка ещё чаще). Обновляется только изменившийся фрагмент: курсор, прокрутка и undo остаются на месте. Если в файле есть ваши несохранённые правки, ничего не затирается, сверху появляется баннер с выбором «Загрузить с диска» или «Оставить мои правки». Если агент удалил файл, вкладка зачёркнута, баннер предлагает закрыть её или сохранить файл заново.

## Редактор

- подсветка синтаксиса Monaco (около 80 языков, плюс toml, vue, svelte, .env)
- цветные пары скобок и линии отступов, подсветка парной скобки
- **indent-rainbow:** уровни отступов закрашены циклом из 4 цветов, отступ не кратный размеру таба подсвечен красным (в markdown и plaintext красное отключено). Размер таба определяется по содержимому файла. Кнопка «Отступы» включает и выключает, «Перенос» переключает перенос строк, настройки запоминаются.

## Проекты и пресеты

Каждая подпапка `projects/` становится проектом сама, плюс пункт «(весь workspace)». Для особых случаев `projects.json`:

```json
[
  {"id": "myapp", "name": "My App", "path": "my-project", "cmd": "agy; exec bash -l"}
]
```

`path` относительный от `projects/` или абсолютный, `cmd` запускается в терминале в папке проекта (после выхода из agy остаётся bash). Терминальная сессия у каждого проекта своя и живёт на сервере: закрыли вкладку и вернулись, agy на месте.

## Настройки агента в графическом режиме

Кнопка **⚙ Настройки агента** в панели терминала открывает форму, в которой два блока:

- **Флаги запуска проекта** (свои у каждого проекта): `--model`, `--mode`, `--effort`, `--sandbox`, `--dangerously-skip-permissions`, `--add-dir` (по папке в строке) и произвольные дополнительные аргументы. Хранятся в `agy-auth/webide.json`.
- **Общие настройки agy** (для всех проектов): форма построена по документации agy и правит `~/.gemini/antigravity-cli/settings.json` (режим агента, подтверждения инструментов, песочница, модель, тема, подробность, редактор и около 20 других). Для объектов `permissions`, `statusLine`, `title`, `sandboxProxy`, `customModelsConfig`, `gcp` есть поля JSON с проверкой.

Две кнопки:
- **Сохранить**: настройки применятся при следующем запуске агента.
- **Сохранить и перезапустить агента (-c)**: сессия проекта перезапускается с новыми флагами и **продолжает последний диалог** (`agy -c`). Если продолжать нечего и agy сразу падает, он запускается заново обычным способом.

Как это устроено и на что обратить внимание:
- agy сохраняет в `settings.json` только отличия от значений по умолчанию, форма делает так же: значение по умолчанию удаляет ключ. Неизвестные форме ключи (`$schema`, `hooks` и т.п.) не трогаются, перед каждой записью создаётся копия `settings.json.webide-bak`, права файла `0600`.
- Если файл повреждён (невалидный JSON), форма предупредит и не перепишет его без вашего подтверждения.
- Флаги проекта подставляются в `cmd` вместо `{AGY_FLAGS}`. Для проектов с автосканом это уже сделано. Если в `projects.json` у пресета свой `cmd`, замените вызов agy на `bash /opt/webide/agy-run {AGY_FLAGS}` (пример в `projects.json`), иначе форма предупредит, что флаги не применятся.
- Документация agy не говорит, подхватывает ли уже запущенный агент правки `settings.json` на лету, поэтому применение сделано через перезапуск. Внутри живой сессии те же вещи можно менять и самим agy: `/config`, `/model`, `/effort`, `/permissions`.
- `agentMode: auto` недоступен для business/enterprise-аккаунтов (agy в этом случае стартует в `default`).
- `--dangerously-skip-permissions` отключает все подтверждения. Включайте, только если понимаете последствия: агент работает с правами контейнера.

## Языки интерфейса (i18n)

В панели терминала доступна кнопка переключения языка **🌐 RU / EN**:

- По умолчанию включены файлы локализации `webide/lang/ru.json` и `webide/lang/en.json`.
- В окне выбора языка можно:
  - Переключаться между русским и английским языками без перезагрузки страницы.
  - **Скачать шаблон `en.json`** в один клик.
  - **Загрузить свой файл перевода (`.json`)** через кнопку загрузки: перевод сразу применяется и сохраняется в `localStorage`.
  - Удалить пользовательский перевод при необходимости.

## Telegram: общение с агентом из мессенджера

Каждый проект = отдельная тема (topic) в группе-форуме. Сообщение в теме уходит в терминал agy этого проекта, а ответом приходит экран агента с кнопками. Бот сам ходит в Telegram через ваш socks-прокси (long polling), входящие порты не нужны. Пока `TG_TOKEN` пуст, мост выключен.

**Настройка (один раз):**
1. @BotFather → `/newbot` → токен в `.env` (`TG_TOKEN`).
2. Перезапустите контейнер, напишите боту `/id`, впишите свой ID в `TG_ALLOWED_USERS` (несколько через запятую), снова перезапустите. Чужие пользователи боту не отвечают.
3. Создайте группу, включите «Темы» (Topics) в её настройках, добавьте бота администратором с правом «Управление темами».
4. В группе напишите `/setup`: для каждого проекта создастся тема. Новые проекты потом: `/newproject имя [git-url]` (создаёт папку или клонирует и сразу делает тему).

**Как пользоваться:** пишете в теме проекта обычный текст, он попадает в agy как ввод. Бот показывает ход работы и, когда агент замолчит на `TG_QUIET` секунд (5 по умолчанию), присылает финальный экран. Кнопки под ним: Enter, Esc, стрелки, 1/2/3, y/n, Tab, Ctrl+C, «Экран» (обновить). Этого хватает, чтобы подтверждать запросы разрешений и выбирать пункты меню.

| Команда | Что делает |
|---|---|
| `/screen` | показать экран агента сейчас |
| `/key down down enter` | нажать клавиши (enter esc tab up down left right ctrl-c ctrl-d space backspace) |
| `/stop` | Ctrl+C |
| `/restart` | перезапустить сессию агента проекта |
| `/git` | `git status -sb` проекта |
| `/projects`, `/bind <проект>`, `/unbind` | список проектов, ручная привязка темы или личного чата |
| `/setup`, `/newproject` | создание тем |

Любое другое сообщение, в том числе `/что-то`, уходит агенту как есть (у agy свои слэш-команды). Если нужно отправить агенту текст, совпадающий с командой бота, поставьте `>` перед ним: `>/screen`. Привязки хранятся в `agy-auth/telegram.json`. Можно написать боту и в личку: `/bind проект`, дальше то же самое без тем.

Важно знать:
- в сообщение помещаются последние ~40 строк экрана, длинную историю смотрите в веб-терминале (сессия одна и та же: что набрали в Telegram, видно в браузере и наоборот);
- агент работает в том же терминале, что и в браузере, поэтому изменения его файлов сразу видны в IDE;
- токен бота это ключ к агенту с правами контейнера: держите `.env` закрытым, `TG_ALLOWED_USERS` заполняйте только своими ID.

## HTTP API агента

Тот же механизм доступен любым скриптам (тот же basic auth, что и у UI). Telegram-бот работает поверх него.

```sh
# отправить задачу и дождаться, пока вывод затихнет на 4 с (максимум 120 с)
curl -u agy:$AUTH_PASS -X POST localhost:7681/api/agent/send \
  -H 'Content-Type: application/json' \
  -d '{"project":"myapp","text":"добавь тесты для utils.py","wait":true,"quiet":4,"timeout":120}'
# → {"alive":true,"screen":"...текст экрана...","idle":4.2}

# нажать клавиши (ответить на вопрос агента)
curl -u agy:$AUTH_PASS -X POST localhost:7681/api/agent/key -H 'Content-Type: application/json' \
  -d '{"project":"myapp","keys":["down","enter"],"wait":true}'

# посмотреть экран без ввода
curl -u agy:$AUTH_PASS 'localhost:7681/api/agent/screen?project=myapp&lines=40'
```

`project` это id проекта (имя папки), сессия запускается сама, если её нет. Если не указывать `"wait"`, ответ придёт сразу, а экран можно опрашивать через `/api/agent/screen`.

## Переменные (.env)

| Переменная | Назначение |
|---|---|
| `AUTH_PASS` / `AUTH_USER` | вход в webide (пароль обязателен) |
| `WEBIDE_BIND` | `127.0.0.1` (по умолчанию) или `0.0.0.0` |
| `GIT_USER_NAME` / `GIT_USER_EMAIL` | автор коммитов |
| `AGY_DWNL_URL` | ссылка на архив agy (по умолчанию 1.5.3) |
| `TG_TOKEN` / `TG_ALLOWED_USERS` | Telegram-мост: токен бота и список разрешённых ID (пусто = мост выключен) |
| `TG_QUIET` | сколько секунд тишины считать окончанием ответа агента (5) |

## Ограничения

- файлы больше 5 МБ и бинарные не открываются, поиск пропускает файлы больше 1 МБ и папки `.git`, `node_modules`, `venv`, `dist`, `build`
- сохранение в UTF-8
- нет stash, rebase, слияния конфликтов в отдельном редакторе: при конфликте после pull файлы помечены `C`, правятся вручную, затем в индекс и коммит (или через терминал)
- если Monaco/xterm не удалось скачать при старте, страница берёт их с cdn.jsdelivr.net, тогда браузеру нужен интернет
